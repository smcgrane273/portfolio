# Content Notes

## Working Title

City That Never Sleeps

## Possible Subtitle

Interactive city-light study

## Medium

Single-file p5.js website / interactive browser sketch.

## Draft Description

An interactive night-city sketch built with p5.js. The project uses a procedural skyline, animated window states, and a moon-triggered recording interaction to explore the city as a living system of small signals.

## Interaction Notes

- Windows gradually move between off and on states.
- Double-clicking a window toggles that window.
- Double-clicking the moon starts a five-second canvas recording.
- The skyline regenerates when the browser window is resized.
