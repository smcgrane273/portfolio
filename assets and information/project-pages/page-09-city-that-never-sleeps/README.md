## Project Summary

`City That Never Sleeps` is an interactive browser-based city-at-night sketch. A dark blue sky, moon, and layered skyline are generated with p5.js. Building windows slowly transition on and off over time, creating a sense of urban sleeplessness and ambient rhythm.

The interaction system includes:

- Double-click a window to toggle its light state.
- Double-click the moon to record a five-second `.webm` capture from the canvas.
- Resize the browser to regenerate the skyline composition.
