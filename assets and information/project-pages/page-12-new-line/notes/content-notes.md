# Content Notes

## Working Title

New Line

## Suggested Subtitle

A generative single-line drawing system.

## Short Description

A p5.js sketch where one continuous line slowly morphs between simple drawn objects on a warm paper-colored canvas.

## Longer Draft Description

`New Line` treats drawing as a continuous state rather than a fixed image. A single path is resampled into hundreds of points, then eased between object outlines so a bird can become a planet, a boat can become a house, and a letterform can become an everyday object. The motion is quiet and slightly imperfect, with noise in the line giving each transformation a hand-drawn feeling.
