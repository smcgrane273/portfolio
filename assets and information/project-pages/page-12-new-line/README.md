## Project Summary

`What is a Line?` is a generative single-line drawing system. A dark line moves across a warm paper-colored canvas, continuously morphing between simple recognizable forms: a bird, plane, apple, hat, house, cat, chair, boat, carrot, infinity symbol, letterform, planet, frog, and coffee cup.

The project uses resampled points so each object can transform into the next as one continuous path. The line subtly drifts through noise, giving the drawing a hand-drawn and slightly unstable quality. A small dot in the corner acts as a recording trigger for a 12-second `.webm` capture.
