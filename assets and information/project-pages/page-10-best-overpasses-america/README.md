## Project Summary

`The Highway Book` is a restrained digital and printable study of American overpasses and highway interchanges. The browser version presents one interchange image at a time with a compressed caption line, source link, and page counter. The pacing is quiet and editorial, letting each piece of infrastructure read like a plate in an image book.

The project includes ten interchange studies:

- High Five Interchange, Dallas, Texas
- Judge Harry Pregerson Interchange, Los Angeles, California
- Four Level Interchange, Los Angeles, California
- Tom Moreland Interchange / Spaghetti Junction, Atlanta, Georgia
- I-10 / I-405 Interchange, Los Angeles, California
- Stack Interchange, Phoenix, Arizona
- Marquette Interchange, Milwaukee, Wisconsin
- Newark Airport Interchange, Newark, New Jersey
- Springfield Interchange / Mixing Bowl, Springfield, Virginia
- I-10 / Loop 1604 Interchange, San Antonio, Texas
