## Project Summary

`Pointillist Eyes` is a p5.js sketch that rebuilds a cropped image of eyes as a field of colored dots. Dot size is driven by image brightness, creating a pointillist portrait with a soft Seurat-like texture. The sketch also includes an interaction: clicking swaps the open-eye image with a closed-eye version for a short blink.

The project includes two image states:

- `eyes.png`: open eyes
- `eyes-closed.png`: closed eyes / blink state
