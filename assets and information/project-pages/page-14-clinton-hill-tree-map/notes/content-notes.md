# Content Notes

## Working Title

Clinton Hill Tree Map

## Suggested Subtitle

An interactive map of 2,792 street trees in Clinton Hill, Brooklyn.

## Short Description

A Leaflet-based civic data interface that maps Clinton Hill street trees by location, health, species, trunk diameter, and stewardship condition.

## Longer Draft Description

`Clinton Hill Tree Map` transforms local tree census data into an interactive neighborhood map. Each tree is plotted as a circle marker, with color indicating health or status and size responding to trunk diameter. Selecting a marker opens a detail panel with species, Latin name, address, sidewalk condition, stewardship, problems, and census metadata.
